🔌 DOA 안경 배열 — 전체 배선표 (2026-07-20 납땜 작업용)

⚡ 납땜 전 USB 뽑기! 그리고 마이크 전원은 반드시 스타 배선(한 점에서 각자 분기) — 공통노드 점퍼 빠짐으로 4채널 전멸했던 전례의 재발 방지가 이번 납땜의 최우선 목표.

① X쌍 — 좌우 마이크 (I2S0 공유 버스)

신호ESP32-S3 핀연결
SCK (BCLK)GPIO 4왼쪽·오른쪽 마이크 공유
WS (LRCLK)GPIO 5왼쪽·오른쪽 마이크 공유
SD (DATA)GPIO 6왼쪽·오른쪽 마이크 공유 (같은 선에 둘 다)
왼쪽 마이크 L/RGNDLeft 슬롯 지정
오른쪽 마이크 L/R3V3Right 슬롯 지정

② Y쌍 — 위(코쪽)·아래 마이크 (I2S1 공유 버스)

신호ESP32-S3 핀연결
SCK (BCLK)GPIO 15위·아래 마이크 공유
WS (LRCLK)GPIO 16위·아래 마이크 공유
SD (DATA)GPIO 17위·아래 마이크 공유
위 마이크 L/RGNDLeft 슬롯 지정
아래 마이크 L/R3V3Right 슬롯 지정

③ 마이크 4개 공통 전원

마이크 핀연결비고
VDD3V3보드에서 별도 선으로 각 마이크에 직접(스타). 분기점이 필요하면 납땜된 분기점만 사용 — 브레드보드 공통노드 금지
GNDGND

④ IMU (MPU-9250 / 9255 / 6500)

IMU 핀ESP32-S3 핀비고
VCC3V3보드 3V3 핀에서 직접 (마이크 스타노드와 별개)
GNDGND
SCLGPIO 9
SDAGPIO 8
AD0GNDI2C 주소 0x68 고정
⚠️ 헤더핀 자체 납땜 필수 — 오늘 두 번 끊긴 최대 말썽꾼

⑤ 규칙·주의

항목내용
금지 핀GPIO 26~32, 33~37 (PSRAM 전용), 0 / 3 / 45 / 46 (스트래핑)
배선 길이I2S 신호선 40cm 이내, 마이크 쪽에 여유 고리(당김 방지)
USB보드 위쪽 USB-C = CH343(COM3) 사용
L/R 핀쌍 안에서 반드시 하나는 GND, 하나는 3V3 — 절대 띄워두지 말 것(부유 금지)
✅ 납땜 후 검증 순서 (Claude에게 "납땜완료"라고 말하면 진행):
① 조용한 상태 레벨 검사 (4채널 균등 확인) → ② 4점 탭 테스트 (위치↔채널 지도 확정) → ③ 수건 위 좌/우/위 박수 (방향·부호 최종 확정 — 부호는 소프트웨어 한 줄이라 배선을 어느 쪽으로 하든 OK)

※ 방향 부호(LAG_SIGN)는 납땜 결과에 맞춰 소프트웨어로 잡으므로, L/R을 표와 반대로 달았어도 다시 지질 필요 없음 — 검증 단계에서 자동으로 맞춰짐.
