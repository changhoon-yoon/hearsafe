실선 = 가로쌍(X, 좌우) 배선, 점선(점묘) = 세로쌍(Y, 전후) 배선. L/R 선은 별도 부품이 아니라 마이크의 L/R 핀을 GND 또는 3V3 라인에 그대로 잇는 것 — 보라색 선이 검정/빨강 선에 합류하는 작은 점(●)이 그 지점입니다.

안경 프레임에 마이크 4개를 십자로 장착합니다. 조립 전에 이 방향 기준부터 팀원과 맞추세요 — 위 = 전방(얼굴이 향하는 쪽), 아래 = 후방, 좌우는 착용자 기준 그대로입니다.

FIG 2AX쌍 (좌우) 배선도 — M1 · ESP32 · M2

M1(왼쪽)·M2(오른쪽)는 SCK/WS/SD 세 선을 공유합니다. 두 마이크를 가르는 건 오직 L/R 핀뿐입니다. ESP32 기판 안의 금색 선은 실드캔 아래로 지나가는 내부 배선(직접 만들 필요 없음)입니다.

FIG 2BY쌍 (전후) 배선도 — M3 · ESP32 · M4

배선 방식은 X쌍과 동일한 원리이나 다른 GPIO(15/16/17), 다른 I2S 포트(I2S1)를 씁니다. 점묘선은 "Y쌍"이라는 표시일 뿐 실제 점퍼선은 X쌍과 같은 실선입니다.

FIG 2CIMU 배선도 — ESP32 · IMU (I2C)

자이로 IMU는 착용 중 고개를 돌려도 방향을 유지시켜주는 핵심 부품입니다. 전원은 마이크와 다른 3V3 핀에서 직접 따세요.

조립 후 검증 절차

  1. ① 채널 확인 (쌍별로, 손가락 톡톡)
    X쌍부터: M1을 톡톡 두드려 대시보드 왼쪽 채널이 튀는지, M2를 두드려 오른쪽 채널이 튀는지 확인. 그다음 Y쌍(M3→전방 채널, M4→후방 채널)도 동일하게. 안 튀면 SD/WS/SCK 배선이나 GND 접촉을 먼저 의심하세요.
  2. ② 방향 확인 (박수만)
    왼쪽에서 박수 → 화면 각도가 180° 근방인지 확인. 바람을 불거나 문지르는 테스트는 금지 — 국소 잡음이라 방향 판정이 안 됩니다.
  3. ③ 반대로 나오면 배선을 바꾸지 말고 코드로
    좌우가 뒤집혀 보이면 배선을 다시 뽑지 말고 pins.h의 LAG_SIGN_X(또는 Y)를 반전해 재업로드하세요. 부호는 이론이 아니라 항상 실측(박수)으로만 확정합니다.
  4. ④ 안 될 때 확인 순서
    1) 브레드보드 GND 공통노드 흔들림(채널 전체가 죽는 가장 흔한 원인) → 2) 마이크 소리구멍 막힘(레벨 자체가 안 나옴) → 3) 핀 오배선(특정 채널만 안 나옴) 순으로 점검하세요.

조립 전 꼭 읽을 것

  • IMU 전원은 마이크와 분리: 브레드보드 공통노드가 아니라 보드 3V3/GND 핀에서 직접 배선 (접촉불량으로 전체가 죽었던 전례).
  • GND 공통노드는 흔들리면 안 됨: 점퍼 삽입 후 살짝 당겨 고정 여부를 확인하세요. 증상 = 톡톡 쳐도 레벨이 수만 이하로 안 올라감.
  • 마이크 소리구멍을 막지 마세요: 테이프나 케이스로 가리면 해당 채널이 죽습니다.
  • 방향 테스트는 반드시 박수로만: 바람/문지르기는 국소 잡음이라 방향이 나오지 않습니다.
  • 진동에 민감: 딱딱한 책상에 프레임이 직접 닿으면 진동이 오탐지를 유발합니다. 착용 상태이거나 수건 위에서 테스트하세요.
  • 모듈 실크스크린은 제조사마다 다를 수 있습니다: 핀 위치가 아니라 인쇄된 핀 이름(VDD/GND/L·R/WS/SCK/SD)으로 연결하세요.
